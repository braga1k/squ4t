squ4t 1.0.1: the notifications carry the app's name, and recording a set makes a sound.

## Get it

Download `squ4t-1.0.1-windows-x64.zip`, unzip it anywhere and run `squ4t.exe`. No installer.
If you run 1.0.0, exit it from the tray menu first and replace both executables; your ledger and
settings stay where they are. The executables are not code-signed: if SmartScreen warns, choose
**More info → Run anyway**.

## What changed

- Reminders are headed **squ4t** with its ring, instead of `squ4t.exe` and a generic icon.
  Clicking one still opens the panel.
- `squ4t.exe` has the ember ring as its icon, and both programs carry version information.
- Recording a set plays one short sound: a weight plate set down on a rubber floor. It is made
  by the app and plays as a system sound, so the **System sounds** slider in Windows' volume
  mixer sets its level or mutes it.

## Checked

- A real reminder fired and captured on screen: headed "squ4t" with the ring; clicking it opens
  the panel
- The same tests as 1.0.0: the ledger against the plugin's `store.py` on 23,309 steps, the
  plugin's tests, and a UI Automation pass over every control

Tested on Windows 11 at 100% scaling. Windows 10, other scales and screen readers are untested.
