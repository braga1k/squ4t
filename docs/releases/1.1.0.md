squ4t 1.1.0: one Record button, the settings behind a cog, and updates from inside the app.

## Get it

Download `squ4t-1.1.0-windows-x64.zip`, unzip it anywhere and run `squ4t.exe`. No installer.
If you run 1.0.0 or 1.0.1, exit it from the tray menu first and replace both executables; your
ledger and settings stay where they are. This is the last time by hand: from 1.1.0 on, the app
updates itself. The executables are not code-signed: if SmartScreen warns, choose
**More info → Run anyway**.

## What changed

- **Record** is one ember button, as wide as the panel. The number of squats is a field inside
  it: click it to type another, or step it with Up and Down.
- The settings moved behind a **cog** in the corner of the panel, which is now 255 tall instead
  of 378. Interval, squats per break, the Reminders switch and Save are there.
- Everything stands on two columns: the two counts, Undo and Snooze, and every pair in the
  settings. Undo and Snooze are the same size (they were 144 and 136 wide).
- **Check for updates** asks GitHub for the latest release of this project; **Update to …**
  downloads it, requires its SHA-256 to match the release's `SHA256SUMS.txt`, replaces both
  programs and restarts the app. The version is shown beside the name in the settings.
- **Auto-update**, off at first. On, the app looks once a day and installs what it finds,
  restarting when the panel is closed. With it off, the app never connects to anything by itself.
- `squ4t-cli update` says whether a newer release exists; `squ4t-cli update install` installs it.

The app used no network before this version. It now uses it for updates only: one request to
GitHub per check, and the download. The checksum comes from the same release as the zip, so it
catches a broken download, not a release changed at its source.

## Checked

- A build labelled 1.0.0 found the published 1.0.1 and installed it, from the panel's button and
  from the command line; both programs then matched the release zip byte for byte
- The same tests as 1.0.1, the UI Automation pass rewritten for the new panel (sizes and columns
  of the buttons included), and six tests of the updater

Not run: the daily automatic check, and the restart an automatic update waits for until the
panel closes. Tested on Windows 11 at 100% scaling. Windows 10, other scales and screen readers
are untested.
