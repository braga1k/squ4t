squ4t 1.0.0: squat reminders in the Windows tray, with daily and all-time rep counts. It brings
[omarchy-squat-break](https://github.com/braga1k/omarchy-squat-break) to Windows 10 and 11.

## Get it

Download `squ4t-1.0.0-windows-x64.zip`, unzip it anywhere and run `squ4t.exe`. No installer.
The executables are not code-signed: if SmartScreen warns, choose **More info → Run anyway**.

## What it does

- A tray ring that empties toward your next break, with the countdown and your totals in its tooltip
- A Windows notification when it is time; clicking it opens the panel
- Record the squats you did, undo the last entry, snooze 5 minutes, pause or resume
- Interval from 1 to 1,440 minutes, 1 to 1,000 squats per break
- `squ4t-cli.exe` for the same ledger from a terminal
- Starts with Windows (turn it off in the tray menu)

The ledger is `%LOCALAPPDATA%\squ4t\ledger.json`, the same file the Omarchy plugin writes, so
your history can move between the two.

## Checked

- The ledger gives the same answer as the plugin's `store.py` on 23,309 recorded steps
- The plugin's own tests, a crash test that kills writes midway, and a UI Automation pass over
  every control
- Panel open in about 70 ms; about 17 MB of memory at rest

Tested on Windows 11 at 100% scaling. Windows 10, other scales and screen readers are untested.
